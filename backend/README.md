# Backend Hotel Gran Capital

## Instalación

```bash
cd backend
npm install
```

Copia `.env.example` como `.env`, configura PostgreSQL y asegúrate de ejecutar los SQL de `../db` sobre `hotelgrancapitaldb`. `BCRYPT_ROUNDS` debe permanecer en `8`.

## Ejecución

```bash
npm run dev
```

Compilación y producción:

```bash
npm run build
npm start
```
